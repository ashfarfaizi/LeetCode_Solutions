<h2><a href="https://leetcode.com/problems/snakes-and-ladders/">909. Snakes and Ladders</a></h2><h3>Medium</h3><hr>

An n x n board is numbered 1 to n*n in a back-and-forth (boustrophedon) order starting from the bottom-left. Some squares hold a snake or ladder that moves you to another square. Rolling a six-sided die each turn, find the fewest moves to reach the last square, or -1 if it can't be reached.
