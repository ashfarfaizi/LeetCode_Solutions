<h2><a href="https://leetcode.com/problems/shortest-completing-word/">748. Shortest Completing Word</a></h2><h3>Easy</h3><hr>

A word completes a license plate if it contains every letter of the plate (ignoring case, digits and spaces) at least as many times as the plate does. Among the given words, return the shortest completing one, preferring the earliest on ties.
