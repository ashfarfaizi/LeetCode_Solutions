<h2><a href="https://leetcode.com/problems/maximum-length-of-pair-chain/">646. Maximum Length of Pair Chain</a></h2><h3>Medium</h3><hr>

Each pair [left, right] has left < right, and pair q can follow pair p when p's right is less than q's left. Pairs may be picked in any order; return the length of the longest chain that can be formed.
