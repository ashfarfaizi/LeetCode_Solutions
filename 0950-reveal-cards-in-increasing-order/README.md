<h2><a href="https://leetcode.com/problems/reveal-cards-in-increasing-order/">950. Reveal Cards In Increasing Order</a></h2><h3>Medium</h3><hr>

Cards are revealed from a deck by repeatedly taking the top card, then moving the next top card to the bottom, until the deck is empty. Arrange the given unique card values so that this process reveals them in increasing order, and return that arrangement.
