<h2><a href="https://leetcode.com/problems/longest-zigzag-path-in-a-binary-tree/">1372. Longest ZigZag Path in a Binary Tree</a></h2><h3>Medium</h3><hr>

A zigzag path in a binary tree starts at any node, picks a direction, and keeps alternating between moving to the left child and the right child. Its length is the number of edges visited. Return the length of the longest zigzag path in the tree.
