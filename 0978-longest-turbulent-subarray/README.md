<h2><a href="https://leetcode.com/problems/longest-turbulent-subarray/">978. Longest Turbulent Subarray</a></h2><h3>Medium</h3><hr>

A subarray is turbulent when the comparison sign between each pair of neighbours flips at every step (up, down, up, ... or down, up, down, ...). Return the length of the longest such subarray.
