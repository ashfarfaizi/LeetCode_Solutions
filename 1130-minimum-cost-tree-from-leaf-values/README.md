<h2><a href="https://leetcode.com/problems/minimum-cost-tree-from-leaf-values/">1130. Minimum Cost Tree From Leaf Values</a></h2><h3>Medium</h3><hr>

Given an array of positive integers that must appear, in order, as the leaves of a binary tree where every internal node has exactly two children, each internal node is worth the product of the largest leaf in its left subtree and the largest leaf in its right subtree. Return the smallest possible sum of internal node values.
