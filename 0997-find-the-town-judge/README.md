<h2><a href="https://leetcode.com/problems/find-the-town-judge/">997. Find the Town Judge</a></h2><h3>Easy</h3><hr>

A town has `n` people and a list of trust pairs `[a, b]` meaning `a` trusts `b`. The judge, if one exists, trusts nobody and is trusted by everyone else. Return the judge's label, or `-1` if there is no such person.
