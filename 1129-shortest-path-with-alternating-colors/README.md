<h2><a href="https://leetcode.com/problems/shortest-path-with-alternating-colors/">1129. Shortest Path with Alternating Colors</a></h2><h3>Medium</h3><hr>

A directed graph on `n` nodes has red edges and blue edges (self-loops and parallel edges allowed). For each node, return the length of the shortest path from node 0 whose edge colours alternate, or `-1` if there is none.
