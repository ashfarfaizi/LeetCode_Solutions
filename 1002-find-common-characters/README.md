<h2><a href="https://leetcode.com/problems/find-common-characters/">1002. Find Common Characters</a></h2><h3>Easy</h3><hr>
<p>Given an array of lowercase words, list every character that shows up in all of the words, repeating a character as many times as it appears in every word (i.e. the minimum count across words). The output order does not matter.</p>
