<h2><a href="https://leetcode.com/problems/number-of-enclaves/">1020. Number of Enclaves</a></h2><h3>Medium</h3><hr>
<p>In a binary grid, 1 is land and 0 is sea. Moving between 4-directionally adjacent land cells, some land cells can reach the grid boundary and walk off. Count the land cells from which it is impossible to reach the boundary.</p>
