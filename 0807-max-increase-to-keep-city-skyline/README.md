<h2><a href="https://leetcode.com/problems/max-increase-to-keep-city-skyline/">807. Max Increase to Keep City Skyline</a></h2><h3>Medium</h3><hr>

An n x n grid gives building heights. Raise buildings as much as possible in total so that the skyline seen from each of the four sides stays the same, and return the total height added.
