<h2><a href="https://leetcode.com/problems/jump-game-iii/">1306. Jump Game III</a></h2><h3>Medium</h3><hr>

Starting at index `start` of a non-negative array, from index `i` you may jump to `i + arr[i]` or `i - arr[i]` as long as you stay inside the array. Decide whether any index holding the value 0 is reachable.
