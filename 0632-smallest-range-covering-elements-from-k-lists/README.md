<h2><a href="https://leetcode.com/problems/smallest-range-covering-elements-from-k-lists/">632. Smallest Range Covering Elements from K Lists</a></h2><h3>Hard</h3><hr>

Given k sorted integer lists, find the narrowest range [a, b] that contains at least one number from each list. When two ranges have the same width, the one with the smaller start wins.
