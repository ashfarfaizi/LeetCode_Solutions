<h2><a href="https://leetcode.com/problems/nearest-exit-from-entrance-in-maze/">1926. Nearest Exit from Entrance in Maze</a></h2><h3>Medium</h3><hr>

A maze is a grid of open cells `.` and walls `+`. Starting from a given open cell, move one step up, down, left or right at a time. Return the fewest steps needed to reach an open border cell other than the starting cell, or `-1` if none is reachable.
