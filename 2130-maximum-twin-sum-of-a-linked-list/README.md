<h2><a href="https://leetcode.com/problems/maximum-twin-sum-of-a-linked-list/">2130. Maximum Twin Sum of a Linked List</a></h2><h3>Medium</h3><hr>

In a linked list of even length `n`, node `i` (0-indexed) and node `n - 1 - i` are twins. Return the largest sum of a node's value and its twin's value.
