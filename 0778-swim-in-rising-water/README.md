<h2><a href="https://leetcode.com/problems/swim-in-rising-water/">778. Swim in Rising Water</a></h2><h3>Hard</h3><hr>

An n x n grid holds distinct elevations. At time t the water level is t, and you can move between adjacent cells only when both are at most t. Find the earliest time at which you can travel from the top-left cell to the bottom-right cell.
