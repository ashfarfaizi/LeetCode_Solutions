<h2><a href="https://leetcode.com/problems/brick-wall/">554. Brick Wall</a></h2><h3>Medium</h3><hr>

A wall is made of rows of bricks with equal total width but varying brick widths. Draw one vertical line from top to bottom that crosses the fewest bricks (passing along an edge does not count as crossing) and return that number. The line may not run along the wall's outer sides.
