<h2><a href="https://leetcode.com/problems/open-the-lock/">752. Open the Lock</a></h2><h3>Medium</h3><hr>

A lock has four circular digit wheels starting at "0000". Each move turns one wheel up or down by one. Some combinations are dead ends that jam the lock. Return the fewest moves needed to reach the target code, or -1 if it cannot be reached.
