<h2><a href="https://leetcode.com/problems/shortest-path-in-binary-matrix/">1091. Shortest Path in Binary Matrix</a></h2><h3>Medium</h3><hr>

In an `n x n` grid of 0s and 1s, find the length (counted in cells) of the shortest path from the top-left to the bottom-right corner that only steps on 0-cells and may move in any of the 8 directions. Return `-1` if no such path exists.
