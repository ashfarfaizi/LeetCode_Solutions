<h2><a href="https://leetcode.com/problems/maximum-subsequence-score/">2542. Maximum Subsequence Score</a></h2><h3>Medium</h3><hr>

Given two equal-length arrays `nums1` and `nums2` and an integer `k`, choose `k` indices. The score is the sum of the chosen `nums1` values multiplied by the minimum of the chosen `nums2` values. Return the largest possible score.
