<h2><a href="https://leetcode.com/problems/rotting-oranges/">994. Rotting Oranges</a></h2><h3>Medium</h3><hr>

A grid holds empty cells, fresh oranges and rotten oranges. Each minute, every fresh orange next to a rotten one (up/down/left/right) becomes rotten. Return the minutes needed until no fresh orange is left, or `-1` if some can never rot.
