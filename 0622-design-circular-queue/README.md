<h2><a href="https://leetcode.com/problems/design-circular-queue/">622. Design Circular Queue</a></h2><h3>Medium</h3><hr>

Implement a fixed-capacity FIFO queue backed by a ring buffer, supporting enQueue, deQueue, Front, Rear, isEmpty and isFull. Front and Rear return -1 when the queue is empty, and the mutating operations report success with a boolean.
