<h2><a href="https://leetcode.com/problems/k-th-smallest-prime-fraction/">786. K-th Smallest Prime Fraction</a></h2><h3>Medium</h3><hr>

Given a sorted array starting with 1 followed by distinct primes, consider every fraction arr[i] / arr[j] with i < j and return the k-th smallest one as a pair [numerator, denominator].
