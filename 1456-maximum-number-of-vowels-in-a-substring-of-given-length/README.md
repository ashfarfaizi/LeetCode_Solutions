<h2><a href="https://leetcode.com/problems/maximum-number-of-vowels-in-a-substring-of-given-length/">1456. Maximum Number of Vowels in a Substring of Given Length</a></h2><h3>Medium</h3><hr>

Given a lowercase string `s` and an integer `k`, return the largest number of vowels (`a`, `e`, `i`, `o`, `u`) found in any substring of `s` with length exactly `k`.
