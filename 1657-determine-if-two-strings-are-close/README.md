<h2><a href="https://leetcode.com/problems/determine-if-two-strings-are-close/">1657. Determine if Two Strings Are Close</a></h2><h3>Medium</h3><hr>

Two strings are close if one can be turned into the other by any number of two operations: swapping the positions of two characters, or swapping all occurrences of one existing letter with all occurrences of another existing letter. Decide whether the given strings are close.
