<h2><a href="https://leetcode.com/problems/time-based-key-value-store/">981. Time Based Key-Value Store</a></h2><h3>Medium</h3><hr>

Design a store that keeps several timestamped values per key. Lookups ask for a key at a given time and should return the value set most recently at or before that time, or an empty string if there is none.
