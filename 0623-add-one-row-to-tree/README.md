<h2><a href="https://leetcode.com/problems/add-one-row-to-tree/">623. Add One Row to Tree</a></h2><h3>Medium</h3><hr>

Insert a new row of nodes with a given value at a given depth of a binary tree. Each node one level above gets two new children; its old left subtree hangs off the new left child and its old right subtree off the new right child. Inserting at depth 1 makes a new root whose left child is the old tree.
