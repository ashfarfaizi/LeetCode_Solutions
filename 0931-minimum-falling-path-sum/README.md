<h2><a href="https://leetcode.com/problems/minimum-falling-path-sum/">931. Minimum Falling Path Sum</a></h2><h3>Medium</h3><hr>

In an n x n integer grid, a falling path starts at any cell of the top row and moves down one row at a time to the cell directly below or one of its diagonal neighbours. Find the smallest possible sum of the cells along such a path.
