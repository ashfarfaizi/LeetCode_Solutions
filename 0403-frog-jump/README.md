<h2><a href="https://leetcode.com/problems/frog-jump/">403. Frog Jump</a></h2><h3>Hard</h3><hr>

Stones sit at increasing positions along a river. A frog starts on the first stone with a first jump of 1 unit, and each later jump must be one less, equal to, or one more than the previous jump (always forward). Decide whether it can reach the last stone.
