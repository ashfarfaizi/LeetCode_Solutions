<h2><a href="https://leetcode.com/problems/solve-the-equation/">640. Solve the Equation</a></h2><h3>Medium</h3><hr>

Given a linear equation in one variable `x` using only `+`, `-`, integer coefficients and a single `=`, return the value of `x` as `"x=#value"`. If every value of `x` works return `"Infinite solutions"`, and if none does return `"No solution"`.
