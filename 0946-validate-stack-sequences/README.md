<h2><a href="https://leetcode.com/problems/validate-stack-sequences/">946. Validate Stack Sequences</a></h2><h3>Medium</h3><hr>

Given two permutations of the same distinct values, one giving the order in which values are pushed onto an initially empty stack and the other the order in which they are popped, decide whether some interleaving of pushes and pops could produce both.
