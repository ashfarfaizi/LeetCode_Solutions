<h2><a href="https://leetcode.com/problems/odd-even-linked-list/">328. Odd Even Linked List</a></h2><h3>Medium</h3><hr>

Rearrange a singly linked list so that all nodes at odd positions (1st, 3rd, ...) come first, followed by all nodes at even positions, keeping the relative order inside each group. Aim for O(1) extra space and O(n) time.
