<h2><a href="https://leetcode.com/problems/pancake-sorting/">969. Pancake Sorting</a></h2><h3>Medium</h3><hr>

You may only reorder the array by reversing a prefix of chosen length k. Given a permutation of 1..n, return a sequence of prefix lengths whose flips sort the array, using at most 10·n flips. Any valid sequence is accepted.
