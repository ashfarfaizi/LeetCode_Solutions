<h2><a href="https://leetcode.com/problems/shortest-unsorted-continuous-subarray/">581. Shortest Unsorted Continuous Subarray</a></h2><h3>Medium</h3><hr>

Find the length of the shortest contiguous block of an integer array that, once sorted on its own, leaves the entire array sorted in non-decreasing order. Return 0 if the array is already sorted.
