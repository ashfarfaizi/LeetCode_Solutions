<h2><a href="https://leetcode.com/problems/path-with-minimum-effort/">1631. Path With Minimum Effort</a></h2><h3>Medium</h3><hr>

On a grid of heights you walk from the top-left to the bottom-right cell, moving up, down, left or right. A route's effort is the largest absolute height difference between two consecutive cells on it. Return the minimum effort over all routes.
